## Non-obvious trade-offs

- **State invalidation (the main lesson here).** Evidence cites are positional. 17a94cb added 11 lines to SecurityConfiguration.java and silently staled all five of its cites, including two in `signup-ok`, which no check noticed. This plan re-cites them. It builds no checker. The SUMMARY names the cite-drift seam as a candidate tracked item (PATTERN_SELECTION step 4).
- **Security and publication.** The error-401 description becomes public in Phase 3 and names a defect class (an anonymous request creating a session). It carries no value, only the cookie name. main is 73 commits ahead of origin/main, so 17a94cb is not deployed. The description therefore describes the code since 17a94cb and never claims what production does.
- **Commit hook.** Every commit here is docs, model text or planning, so `--no-verify` is allowed (project CLAUDE.md). It skips the hook's gitleaks and LikeC4 steps. The plan replaces them with `sync.mjs check`, the self-test, and leak `rg` gates over exactly the files changed; gitleaks still runs in CI on a push, which this plan does not make.
- **Performance.** Measured at planning: drill replay 1 min 49 s, self-test 43 s, check and export about 3 s. The full gate runs once, in Task 3; Tasks 1 and 2 run only check and export.
- **Rendered sizes.** The standard's Phase 2 table records natural sizes from the 2026-10-28 PNG export. A longer description or step title can change a rendered size. No PNG export is run here (the column is a dated record, judged against no bound), and the SUMMARY says so.
- **Chart defaults.** Which targets kube-prometheus-stack scrapes by default comes from the chart, not this repo. The text names them as chart defaults and either cites the chart's values file at the pinned version, or says it was not read.
</tradeoffs>
