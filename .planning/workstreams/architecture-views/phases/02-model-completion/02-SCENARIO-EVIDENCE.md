# Phase 2 scenario evidence

Format: one section per scenario view, `## view <id>`, with one table row per step in the order the view draws them (the `#` column is the step number). Each row names a file:line read in the plan that drew the view and quotes it verbatim, or states `authored: <reason>` when no line states the step. A second cite in the same cell is separated by ` ; `, and so are its quotes. LikeC4 checks only that a step's participants exist, so this file is the only tie between a step and the code; a code change can stale a step without failing any check.

Statement order for the SQL steps is read from the code, not observed on the wire, unless a row says it was measured.
