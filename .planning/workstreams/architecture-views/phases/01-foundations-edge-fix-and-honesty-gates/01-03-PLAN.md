## Non-obvious trade-offs
- **Performance:** every staged k8s path now runs the LikeC4 step, about 1 s, inside a hook whose Gradle gates already take about 4 minutes. The guard adds six `existsSync` calls per check.
- **State invalidation:** unchanged known hole: the hook reads the working tree, not the index, so an unstaged fix can mask a staged defect; CI checks the committed tree.
- **Security:** the widened trigger closes a local gate bypass for k8s/platform, k8s/overlays and k8s/monitoring (T-01-08); exit 4 keeps a missing or unparseable tree from failing open (T-01-07); the docs-only Task 3 commit skips the hook, accepted under the project CLAUDE.md (T-01-10).
</tradeoffs>

Data flow in three sentences: before reading manifests, check() confirms each of the six k8s trees exists under --root and exits 4 naming any that is missing, so a scratch copy or checkout that lost a tree can never read as clean. The hook lists the staged paths under its trigger pathspecs, now including the whole k8s tree, and runs the check only when that list is non-empty; status 1 is refused as drift and any other non-zero status is refused as "did not run to completion". The selftest builds scratch repos from the tracked tree, commits a deliberate break through the installed hook, and asserts the banner, the refusal text and the named finding.

Purpose: the gates Phase 2 relies on cannot be skipped by a missing directory or by committing outside the old trigger paths, and the documentation states the checks as built.

</objective>
