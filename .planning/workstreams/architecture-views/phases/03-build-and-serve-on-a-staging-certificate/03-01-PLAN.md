The research settled the server (Open Question 1) by measurement and the layout (Open Question 2) by reading the code that checks it. Both matrices are copied here from 03-RESEARCH.md; plans 02 to 07 refer back to this block.

| Approach | Pros / Cons | Why picked |
|---|---|---|
| (a) nginx-unprivileged 1.30.6-alpine-slim by digest, fallback only for extensionless paths, conf baked into the image | Pro: deep links answer 200, a missing `/assets/*.js` answers a real 404, no route list to maintain, 4.0 MiB anon in the local run. ## Non-obvious trade-offs
- **Pipeline cost (Pitfall 1):** `.github/**` is not in deploy.yml's `paths-ignore`, so the commit that adds the workflow will start one run of the whole app pipeline when it is pushed (plan 02). The Dockerfile and nginx.conf live under `docs/` precisely so that later edits to them do not.
- **Trigger list leaves out `docs/architecture/sync.mjs`, although the build job runs it (a choice, not an omission):** the static output does not depend on the script, so a gate edit would rebuild and roll the site for unchanged bytes; invariant-checks.yml's likec4-model-drift job already runs `sync.mjs check` on every push and pull request (it matches `**`); and a script change that rewrites the generated model file reaches the filter through `docs/architecture/model/**`. The workflow header states the same.
- **Memory:** nginx used 4.0 MiB anon with four workers locally; the VPS has the same CPU count. The real limit comes from the VPS ladder in plan 03, never from this number.
- **Security:** the image runs as user 101, read-only root, all capabilities dropped; `root /srv/site` keeps the image's own `50x.html` out of the web root. A missing asset gets a 404 with no `Cache-Control: immutable`, so a browser never pins a failed asset for a year (no `always` on the assets location, measured).
- **State invalidation:** builds are not byte-reproducible (hashed asset names differed between a host and a container build), so the artifact hand-off, not a rebuild, is what keeps "tested" equal to "pushed".
- **Recorded assumptions:** A8 (no Dependabot docker ecosystem for the nginx base, same debt as the backup image) is accepted and named in the threat register. A9 (a future LikeC4 route ending in a dotted segment without a slash would hit the extension rule) is written as a comment in nginx.conf. A1 (download-artifact v4 pairs with upload-artifact v4) is settled by plan 02's first real run. A build stamp and `--build-webcomponent=false` are not folded in (research open questions 3 and 5).
</tradeoffs>
