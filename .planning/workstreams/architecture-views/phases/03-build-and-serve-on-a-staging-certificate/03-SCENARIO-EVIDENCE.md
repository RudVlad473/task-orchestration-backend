# Phase 3 scenario evidence

Format: one section per scenario view, `## view <id>`, with one table row per step in the order the view draws them (the `#` column is the step number). Each row names a file:line read in the plan that drew the view and quotes it verbatim. A second cite in the same cell is separated by ` ; `, and so are its quotes. After a ` ; ` that begins `observed:`, a row names the record line in this phase directory where the step was seen happening; that quote is the record line as written. LikeC4 checks only that a step's participants exist, so this file (03-SCENARIO-EVIDENCE.md) is the only tie between a step and the workflow or the manifests; a change to either can stale a step without failing any check.
